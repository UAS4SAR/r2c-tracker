# v1.4.95 — iPad device authorization reuse

Enables iOS in the existing explicit device-replacement workflow. Candidate and replacement authorization retain the same organization, member, platform, model, age, installation, and credential-state checks. The endpoint advertises supported platforms so the iPad app can wait for server availability. Choosing a prior device restores its canonical name and transfers retained ownership; deployment alone does not replace any customer authorization.

The release also updates urllib3 from 2.7.0 to 2.8.0 after the dependency gate reported CVE-2026-97687, CVE-2026-97688, and CVE-2026-97689. The initial gate correctly failed. The subsequent exact-source qualification passed with no known dependency vulnerabilities.

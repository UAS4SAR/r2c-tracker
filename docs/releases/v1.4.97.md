# v1.4.97 — ownership claims and Drone Ownership configuration

Aircraft ownership claims and owner leases are written together. A failed write does not grant the claim, a replacement must name the current claim, and an older lease cannot overwrite a newer one. Duplicate ownership scope is refused before the unique index is created, and the statements use fixed table names.

Drone Ownership travels on the existing organization-configuration snapshot. The value is optional. Accepted modes are `all_detected`, `streaming_device`, and `streaming_shared_incident`. A snapshot from an older app that omits the field keeps the published value. The proposal review shows the before and after values. Approval remains limited to an organization owner or config administrator. There is no device or admin control that publishes the setting without that review.

This is compatible with currently installed tablets. RID2Caltopo 2.5.10 sends the field. Older apps omit it. No minimum app build change is required.

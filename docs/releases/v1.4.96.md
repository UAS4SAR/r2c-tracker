# v1.4.96 — persistent device names

Authorized active organization devices can name themselves through the authenticated device endpoint. Names are trimmed, validated, unique among active organization credentials, and retained across reconnects and explicit device replacement. Live stream labels follow the new name; historical recordings retain their original metadata. The schema change adds a default-empty custom name column and preserves older revision compatibility.

Mobile v2.5.1 (342) adds the Apple naming form. Existing mobile versions remain supported; store recommendations must remain at their currently published values until the mobile release completes.

The first qualification passed all 429 tests and runtime/migration checks, then stopped because this workstation lacked the pinned security tools. After installing those tools, the security gate identified CVE-2026-104874 in multidict 6.7.1. The lock now uses the reported fixed version 6.9.1. Secret-baseline changes were verified to contain only line-number metadata; all fingerprints are unchanged. Final qualification and deployment evidence will be recorded after completion.

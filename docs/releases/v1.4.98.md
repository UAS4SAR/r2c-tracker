# v1.4.98 — dependency audit fixes

Updates the locked runtime dependencies that blocked v1.4.97 qualification:

- aiohttp 3.14.5
- certifi 2026.10.23
- dnspython 2.9.2
- pyasn1 0.6.5
- yarl 1.25.1, required by aiohttp 3.14.5

`pip-audit` against `requirements.lock` reported no known vulnerabilities after this update. v1.4.97 remains the ownership-claim and Drone Ownership snapshot release and is not retagged. This version is the candidate that can pass the documented security gate.

No application behavior change is intended beyond the dependency updates. Drone Ownership remains an optional organization-configuration snapshot field. Older apps that omit it keep the published value.
